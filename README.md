# 人生决策器

人生决策器（Decide Better）是一个用于重要个人与工作决策的跨平台 Agent Skill。核心指令位于 `SKILL.md`：Codex 可原生识别它，其他支持 Skill、项目指令或自定义指令的智能体也可加载同一份核心内容。Codex 中的调用名为 `$decide-better`。

## English quick start

`SKILL.md` is the portable source of truth. Load the whole folder in an agent that supports local skills, or load `SKILL.md` as a project/custom instruction in another agent. `agents/openai.yaml` is optional Codex-only UI metadata. See [COMPATIBILITY.md](COMPATIBILITY.md) for integration patterns and limits.

## 项目解决什么问题

现实中的关键决策通常同时存在信息不完整、结果不确定、因素相互影响和选择代价难以比较等问题。人们容易忽略基础概率，只寻找支持既有观点的信息，或只预测成功机会而低估失败成本。

人生决策器不会替用户武断地“拍板”，而是帮助用户区分：

- 什么更可能发生；
- 哪个方案相对更值得选择；
- 判断错误时，损失是否可以承受；
- 下一步怎样行动，才能保留选择权。

它最终输出条件式建议、置信度、关键假设、机会成本、最小下一步和结论改变条件。

## 主要功能

- **先问后评**：只追问可能实质改变建议的信息；信息无法获得时，使用明确假设或分支分析继续推进。
- **快速与深度模式**：默认进行快速分析；重要且高度不确定、不可逆或下行风险显著的决策会进入深度模式。
- **贝叶斯证据校准**：从基础率和竞争假设出发，检查证据的真实性、判别力、增量性、稳健性与决策相关性。
- **信息分层**：区分基础规律、分析洞察和实时信号，并记录来源、日期、适用范围、独立性和失效条件。
- **系统思维**：检查反馈、延迟、阈值、外部依赖、利益相关者反应和二阶影响。
- **机会成本分析**：比较当前方案、维持现状和最佳可行替代方案，识别直接成本、隐性成本与不确定性成本。
- **承受力与选择权设计**：检查最坏合理情景和恢复能力，优先设计小规模试验、分阶段投入、止损线与退出条件。
- **条件式输出**：说明推荐在什么条件下成立、置信度为何如此，以及哪些新信息会改变结论。

当可靠概率数据不足时，Skill 会使用定性证据强度或区间，不会编造精确概率。医疗、法律和投资等高风险问题只提供辅助分析，不替代专业人士。

## 安装方法

本项目不需要安装依赖，也不包含执行脚本。`SKILL.md` 是所有平台共享的核心；请始终连同 `references/` 一起保留。不同智能体对目录、自动发现和自定义指令的支持不同，因此分为以下三种接入方式。

### Codex

本地开发推荐使用软链接，使项目修改自动同步到安装版本：

```bash
mkdir -p ~/.codex/skills
ln -s /你的绝对路径/decide-better ~/.codex/skills/decide-better
```

软链接结构示例：

```text
~/.codex/skills/decide-better -> /absolute/path/to/decide-better
```

也可以直接复制目录，但以后修改项目时需要重新复制：

```bash
cp -R /你的绝对路径/decide-better ~/.codex/skills/decide-better
```

安装或更新后，新建一个 Codex 任务；如果没有识别到 Skill，完全退出并重新打开 Codex。

### 其他智能体

- **支持 `SKILL.md` 或 Agent Skills 的平台**：按该平台的官方目录约定复制整个项目文件夹；不要只复制 `SKILL.md`，以免深度模式无法读取 `references/deep-analysis.md`。
- **只支持项目规则或自定义指令的平台**：将 `SKILL.md` 的完整内容作为项目级或自定义指令，并在平台允许时同时提供 `references/deep-analysis.md`。可使用该平台自己的规则文件名，不需要伪造 Codex 的 `agents/openai.yaml`。
- **普通对话式智能体**：上传 `SKILL.md` 和 `references/deep-analysis.md`，或在自定义指令中粘贴 `SKILL.md`；然后直接描述要做的关键决策。

完整的接入原则、运行时映射与已知边界见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 使用方法

显式调用：

```text
$decide-better 我正在考虑辞职创业，请先询问可能改变结论的关键信息。
```

指定快速模式：

```text
使用 $decide-better 快速分析：我应该现在买车，还是再等半年？
```

指定深度模式：

```text
使用 $decide-better 深度分析这次业务转型，重点检查证据、系统影响、机会成本和最坏情景。
```

Skill 仅允许显性调用。请在请求中使用 `$decide-better`；仅描述决策问题而不点名 Skill 时，Codex 不会自动加载它。

## 输入输出示例

### 输入

```text
我收到两个工作机会。A 的薪资高 25%，但需要搬家；B 的团队更成熟，晋升路径也更明确。我需要在一周内决定。伴侣暂时无法搬家，现有储蓄能覆盖 8 个月支出。请帮我分析。
```

### 输出

```text
决策框架：在一周内从 A、B 和维持现状中选择，重点权衡职业成长、家庭安排和财务安全。

条件式建议：如果未来两年的首要目标是职业成长，且异地安排最多能维持六个月，先验证 A 的实际授权范围，同时保留 B；如果伴侣无法在可接受期限内搬家，则 B 更稳健。

置信度：中。薪资和家庭约束较清楚，但两个岗位的实际晋升概率仍主要来自招聘方陈述。

主要机会成本：选择 A 会放弃 B 的成熟平台和较低的家庭摩擦；选择 B 会放弃更高收入和可能更大的职责空间。

最坏合理情景：选择 A 后实际职责不及预期，同时长期异地影响家庭关系。现有信息不足以判断这一结果是否在可承受范围内。

最小下一步：分别询问两位未来直属主管，了解过去两年同岗位人员的晋升、离职和职责变化，并确认 A 是否存在明确的过渡安排。

结论改变条件：A 能提供可信的远程过渡方案，或 B 的晋升路径缺乏实际案例。
```

实际输出会根据决策的重要性、信息质量和用户目标调整深度，不保证预测结果，也不会替用户执行外部行动。
